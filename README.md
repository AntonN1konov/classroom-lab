# YandexGPT Office Laboratory

Виртуальный кабинет-лаборатория для совместной работы с YandexGPT для вузов.

## Описание

Система предназначена для организации коллективной работы преподавателей и студентов с контекстным окном YandexGPT. Решает проблемы синхронизации ответов ИИ и обеспечивает полный контроль преподавателя над использованием ИИ в учебном процессе.

## Основные возможности

- **Двойная чат-система**: Коллективный чат с YandexGPT и групповой чат студентов с преподавателем
- **Контекстные окна двух уровней**: 
  - Уровень 1: Прямой ввод запросов преподавателем в YandexGPT
  - Уровень 2: Ввод промтов студентами с последующей проверкой преподавателем
- **Управление доступом**: Разделение ролей (преподаватель/студент) с контролем доступа
- **Архивация данных**: Хранение чатов, сессий и загруженных файлов
- **Экспорт документов**: Формирование документов из промтов и ответов (PDF, DOCX)
- **Статистика**: Учет использования токенов и активности пользователей

## Установка для преподавателя (Windows)

Ничего, кроме установщика, не нужно: Python, Node.js и база данных уже внутри.

1. Скачайте `ClassroomLab-Setup-x.y.z.exe` со страницы [Releases](https://github.com/AntonN1konov/classroom-lab/releases/latest) и запустите.
2. Запустите **Classroom Lab** с рабочего стола. Откроется окно сервера и браузер.
3. При первом запуске выберите модель (потом её можно сменить кнопкой **«Настройки ИИ»** в кабинете преподавателя):
   - **Демо-режим** — бесплатно, без модели: тестовые ответы, чтобы проверить интерфейс;
   - **Локальная модель (Ollama)** — бесплатно, модель работает на этом компьютере: установите [Ollama](https://ollama.com/download) и выполните `ollama pull qwen2.5:3b`;
   - **YandexGPT** — платно, по тарифам Yandex Cloud: нужны Folder ID и API-ключ сервисного аккаунта с ролью `ai.languageModels.user` (область действия ключа `yc.ai.languageModels.execute`).

   Кнопка «Проверить подключение» отправляет пробный запрос до сохранения настроек.
4. Зарегистрируйтесь как преподаватель и создайте сессию.
5. Студентам продиктуйте адрес из окна сервера, например `http://192.168.1.10:8000`: им достаточно браузера, устанавливать ничего не нужно. Компьютеры должны быть в одной сети.

Сервер работает, пока открыто его окно. Данные (база SQLite, экспортированные документы, настройки) хранятся в `%APPDATA%\ClassroomLab` и сохраняются при переустановке.

> Windows может показать предупреждение SmartScreen, так как установщик не подписан сертификатом: «Подробнее» → «Выполнить в любом случае».

## Запуск для разработки

### Требования

- Python 3.9+
- Node.js 18+
- PostgreSQL 12+
- Yandex Cloud аккаунт с API ключами

### Backend

1. Перейдите в директорию backend:
```bash
cd backend
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

5. Настройте переменные окружения в `.env`:
- `DATABASE_URL` - строка подключения к PostgreSQL
- `SECRET_KEY` - секретный ключ для JWT
- `YANDEX_CLOUD_FOLDER_ID` - ID папки в Yandex Cloud
- `YANDEXGPT_API_KEY` - API ключ для YandexGPT

6. Создайте базу данных PostgreSQL:
```sql
CREATE DATABASE yandexgpt_lab;
```

7. Запустите сервер:
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Backend будет доступен по адресу: http://localhost:8000

### Frontend

1. Перейдите в директорию frontend:
```bash
cd frontend
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите dev-сервер:
```bash
npm run dev
```

Frontend будет доступен по адресу: http://localhost:3000

## Использование

### Регистрация

1. Откройте приложение в браузере
2. Нажмите "Зарегистрироваться"
3. Заполните форму регистрации
4. Выберите роль: Преподаватель или Студент

### Преподаватель

1. Войдите в систему с ролью преподавателя
2. Создайте новую сессию
3. Добавьте студентов в сессию
4. Используйте КО YandexGPT (Уровень 1) для прямых запросов
5. Проверяйте и одобряйте запросы студентов из КО студентов (Уровень 2)
6. Экспортируйте сессии в PDF или DOCX

### Студент

1. Войдите в систему с ролью студента
2. Выберите доступную сессию
3. Просматривайте коллективный чат с YandexGPT
4. Используйте КО студентов (Уровень 2) для отправки вопросов на проверку
5. Общайтесь в групповом чате с преподавателем и другими студентами

## Статус

Проект реализует ядро технического задания; часть требований ещё в работе.

### Реализовано
- **Роли и доступ:** преподаватель и студент, хеширование паролей (bcrypt), аутентификация по JWT, доступ студента только к своим сессиям.
- **Двойная чат-система:** коллективный чат с YandexGPT и групповой чат студентов с преподавателем, оба хранятся в БД.
- **Контекстные окна двух уровней:**
  - уровень 1 — преподаватель отправляет запросы напрямую;
  - уровень 2 — студент отправляет промт, преподаватель одобряет его, и только после этого промт уходит в модель.
- **Общий контекст группы:** модель получает историю одобренных сообщений сессии, все участники видят одни и те же ответы.
- **Экспорт** промтов и ответов сессии в PDF и DOCX.
- **Управление составом сессии:** добавление, поиск и удаление студентов.
- **Учёт токенов:** расход токенов по каждому запросу сохраняется в БД.
- **Установщик для Windows:** `Setup.exe` собирается и проверяется автоматически в GitHub Actions.
- **Выбор модели:** YandexGPT, бесплатная локальная модель через Ollama или демо-режим без модели; проверка подключения из интерфейса.
