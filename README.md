# YandexGPT Office Laboratory

Виртуальный кабинет-лаборатория для совместной работы с YandexGPT для вузов.

## Описание

Система предназначена для организации коллективной работы преподавателей и студентов с контекстным окном YandexGPT. Решает проблемы синхронизации ответов ИИ и обеспечивает полный контроль преподавателя над использованием ИИ в учебном процессе.

## Основные возможности

- **Двойная чат-система**: Коллективный чат с YandexGPT и групповой чат студентов с преподавателем
- **Контекстные окна двух уровней**: 
  - Уровень 1: Прямой ввод запросов преподавателем в YandexGPT
  - Уровень 2: Ввод промтов студентами с последующей проверкой преподавателем
- **Управление доступом**: Разделение ролей (преподаватель/студент) с контролем доступа
- **Архивация данных**: Хранение чатов, сессий и загруженных файлов
- **Экспорт документов**: Формирование документов из промтов и ответов (PDF, DOCX)
- **Статистика**: Учет использования токенов и активности пользователей

## Установка и запуск

### Требования

- Python 3.9+
- Node.js 18+
- PostgreSQL 12+
- Yandex Cloud аккаунт с API ключами

### Backend

1. Перейдите в директорию backend:
```bash
cd backend
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

5. Настройте переменные окружения в `.env`:
- `DATABASE_URL` - строка подключения к PostgreSQL
- `SECRET_KEY` - секретный ключ для JWT
- `YANDEX_CLOUD_FOLDER_ID` - ID папки в Yandex Cloud
- `YANDEXGPT_API_KEY` - API ключ для YandexGPT

6. Создайте базу данных PostgreSQL:
```sql
CREATE DATABASE yandexgpt_lab;
```

7. Запустите сервер:
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Backend будет доступен по адресу: http://localhost:8000

### Frontend

1. Перейдите в директорию frontend:
```bash
cd frontend
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите dev-сервер:
```bash
npm run dev
```

Frontend будет доступен по адресу: http://localhost:3000

## Использование

### Регистрация

1. Откройте приложение в браузере
2. Нажмите "Зарегистрироваться"
3. Заполните форму регистрации
4. Выберите роль: Преподаватель или Студент

### Преподаватель

1. Войдите в систему с ролью преподавателя
2. Создайте новую сессию
3. Добавьте студентов в сессию
4. Используйте КО YandexGPT (Уровень 1) для прямых запросов
5. Проверяйте и одобряйте запросы студентов из КО студентов (Уровень 2)
6. Экспортируйте сессии в PDF или DOCX

### Студент

1. Войдите в систему с ролью студента
2. Выберите доступную сессию
3. Просматривайте коллективный чат с YandexGPT
4. Используйте КО студентов (Уровень 2) для отправки вопросов на проверку
5. Общайтесь в групповом чате с преподавателем и другими студентами
